### Terraform Installation Commands;

```bash
sudo yum install -y yum-utils
sudo yum-config-manager --add-repo https://rpm.releases.hashicorp.com/AmazonLinux/hashicorp.repo
sudo yum -y install terraform
terraform --version
```

### Create  a folder terraform-project and navigate to it

```bash
mkdir terraform-project
cd terraform-project
```
### Create IAM role with admin access and attach it to EC2 instance in AWS console
Why do we need to attach IAM role to EC2 instance?
- To allow terraform to authenticate and interact with AWS services using the permissions defined in the IAM role
### Create a file main.tf and add the following code

```bash
provider "aws" {
  region = "ap-south-1"
}
```
### Initialize the project

```bash
terraform init
```

Run `ls -la` to check the files created by terraform

We will see a folder called `.terraform` which contains the necessary plugins and a file called `terraform.lock.hcl` which tracks the versions of the providers.

### Write a resource code to create an EC2 instance

```bash
resource "aws_instance" "myfirstinstance" {
  ami           = "ami-123" # Amazon Machine Image ID for the EC2 instance which is OS. We can give ami id of our choice. For example, if we want to create an EC2 instance with Amazon Linux 2, we can use the following ami id: ami-0c55b159cbfafe1f0 (for ap-south-1 region)
  instance_type = "t2.micro" # Type of EC2 instance (e.g., t2.micro, t2.small, etc.)
}
```

### Apply the configuration to create the EC2 instance

```bash
terraform fmt
terraform plan # what will happen before execution
terraform apply # it is used to create the resources using .tf file . It will ask for confirmation before creating the resources. Type "yes" to proceed.
terraform destroy # it is used to delete the resources created by using .tf files. It will ask for confirmation before destroying the resources. Type "yes" to proceed.
cat terraform.tfstate # to check the state of the resources created by terraform. It will show the details of the resources created, such as the resource type, resource id, and other attributes. This file is automatically generated by terraform and should not be manually edited. It is used by terraform to keep track of the resources it manages.
```

To create 3 instances, we can use the `count` parameter in the resource block as follows:

```bash
resource "aws_instance" "myfirstinstance" {
  ami           = "ami-123"
  instance_type = "t2.micro"
  count         = 3 # This will create 3 instances
}
```
```bash
terraform apply --auto-approve # This will create the resources without asking for confirmation
```
### This will list all the resources managed by terraform

```bash
terraform state list 
```

### delete one instance

```bash
terraform state list  # This will list all the resources managed by terraform. We will see 3 instances in the list as follows:
terraform destroy --auto-approve -target=aws_instance.myfirstinstance[0] # This will destroy the first instance created by terraform
```

**vvp**

- current state --- actual state of infr. resources --- tracks this by using terraform.tfstate file.

- desired state --- it is what you define in the configuration files --- main.tf file

logic: Now i have deleted one instance, so current state is 2 instances and desired state is 3 instances. When i run `terraform apply`, So terraform will create one instance to match the desired state. This is how terraform works to maintain the desired state of infrastructure.

What happens if infrastructure is manually changed outside Terraform?

This is called: `Configuration Drift`

Terraform detects the drift during plan or apply and attempts to reconcile infrastructure back to the declared configuration.
```bash
terraform refresh
```

### Adding the key pair to the EC2 instance

```bash
resource "aws_instance" "myfirstinstance" {
  ami           = "ami-123"
  instance_type = "t2.micro"
  count         = 3
  key_name      = "my-key-pair" # This key pair should be present in aws console before applying the configuration. You can create a key pair in AWS console and use its name here.
}
```
