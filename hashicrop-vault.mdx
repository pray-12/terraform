**HashiCorp Vault** is a secret management tool used to securely store sensitive information like passwords, API keys, and tokens. 
It provides encryption, access control, audit logging, and dynamic secret generation for secure infrastructure and application management.

## What is HashiCorp Vault?

**HashiCorp Vault** is a secret management tool used to securely store and manage:

- Passwords
- API Keys
- Tokens
- Database Credentials
- SSH Keys
- Certificates

---

# 🏢 Real Scenario

Suppose an application needs a database password.

❌ Bad Practice:
```python
password = "Admin123"
```

Problems:
- Exposed in code
- Can leak in GitHub
- Security risk

---

# ✅ Better Solution Using Vault

```text
Application → Vault → Get Secret Securely
```

Vault securely stores and provides secrets only to authorized users/applications.

---

# 🚀 Step 1 — Install Vault

## Ubuntu Installation

```bash
sudo apt update
sudo apt install vault -y
```

Check version:

```bash
vault --version
```

---

# 🚀 Step 2 — Start Vault Server (Development Mode)

```bash
vault server -dev
```

Output:

```text
Root Token: hvs.xxxxx
```

Vault starts locally in development mode.

---

# 🌍 Step 3 — Configure Environment Variable

Open another terminal:

```bash
export VAULT_ADDR='http://127.0.0.1:8200'
```

---

# 🔑 Step 4 — Login to Vault

```bash
vault login
```

Paste the root token generated earlier.

---

# 🔐 Step 5 — Store Secret

Store database credentials:

```bash
vault kv put secret/db \
username="admin" \
password="Admin123"
```

---

# 📥 Step 6 — Retrieve Secret

```bash
vault kv get secret/db
```

Example Output:

```text
====== Secret Path ======
secret/data/db

====== Data ======
username    admin
password    Admin123
```

---

# ❌ Step 7 — Delete Secret

```bash
vault kv delete secret/db
```

# 🔒 Important Vault Concepts

## 1. Authentication

Vault verifies:
- Users
- Applications
- Jenkins
- Kubernetes
- Terraform

before providing secrets.

---

## 2. Policies

Policies define permissions.

Example:
```text
Developer → Read-only access
Admin → Full access
```

---

## 3. Secret Engines

Vault supports multiple secret engines:

- KV Secrets
- AWS Secrets
- Database Secrets
- Kubernetes Secrets
- PKI Certificates

---

# 🔥 Dynamic Secrets (Important Feature)

Vault can generate temporary credentials automatically.

Example:

```text
Username: temp-user
Password: x7hd92
Validity: 1 hour
```

After expiry:
- Credentials become invalid automatically.

This improves security significantly.

## How Does Vault Store Secrets?

Vault stores secrets inside encrypted storage called a:

```text
Secret Engine
```

Example:

```text
vault kv put secret/db \
username="admin" \
password="Admin123"
```

Retrieve secret:

```text
vault kv get secret/db
```

Vault encrypts data before storing it.
