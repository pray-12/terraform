- **Terraform** is used for provisioning infrastructure.
- **Ansible** is used for configuration management and application deployment.

### Terraform
- Creates servers in AWS

Example:

- Create EC2 instance
- Create VPC + Subnets
- Setup Load Balancer

✔️ Works best for:

- AWS, Azure, GCP infra provisioning

### Ansible
- Connects to those servers
- Installs software
- Configures apps

Example:

- Install nginx on 10 servers
- Update config files
- Restart services

✔️ Works best for:

- Server configuration
- Application deployment
